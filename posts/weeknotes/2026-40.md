## PETALS

Mostly reviewing and housekeeping this week rather than building.

The Warp changes were the interesting ones. **Copyable snapshot results** landed, and they'll be available to all users soon, which should make it much easier to take your team's results somewhere else. Warp also cached the report petal averages per instance to cut down on repeat queries. And the **cookie consent banner** is up as a PR, well overdue. Analytics stays switched off until someone accepts, and you can withdraw consent again from the footer.

Brian's "Chart 10" PR also merged. It's part of encouraging more paying customers, one of my goals for the end of the year, so I gave it a quick test and moved on.

The bit of housekeeping I'm most pleased with is writing our PR conventions into the marketing site's `CLAUDE.md`, so any agent I point at the repo opens PRs the way I like them without being reminded:

```markdown
## Pull requests

When creating a PR for this repo, set the following in GitHub:

- Project: `PETALS 🌺`
- Milestone: the current season (e.g. `Autumn 2026`)
- Labels: `Claude`, plus `Content` if the PR is for content or blog posts
```

## OKR Daily Card

![OKR Daily Card desktop view](/img/assets/2026/09/okr-daily-card-desktop.png)

Two gaps in [OKR Daily Card](https://okr.sijobling.com/) got closed this week. You can now **edit an outcome** after creating it (title, key results, tasks and completion timeline), and **add a daily action** to an existing outcome without starting it again from scratch.

Both check you own the objective before changing anything, and both have unit tests. Jules did the build, I reviewed it and merged it.

![OKR Daily Card's new Edit outcome button and Add action modal, shown on the House Finesse listenership outcome](/img/assets/2026/10/okr-add-action-modal.png)
